# docs-shell (sandbox)

Placeholder site shell for testing the docs portal. Same layout as the production shell repository:

| Path | Holds |
| --- | --- |
| `{locale}/home/` | the per-language home landing page |
| `{locale}/category/{Category}/` | category pages |
| `{locale}/header.yaml`, `footer.yaml` | site chrome |
| `{locale}/ui.yaml` | interface strings |
| `{locale}/site-images/` | images the chrome references |

Published from `landing_dev` and `landing_prod`; `main` is never published.
